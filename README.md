# IDK — Forum & Real-time Chat Backend

> Форум, потому что я не застал времена, когда они были популярны.

## О проекте

**IDK** — это бэкенд-приложение на FastAPI, которое объединяет классический форум
(посты и древовидные комментарии) с полноценной системой реал-тайм чата
(диалоги, сообщения, непрочитанные, вложения). Проект построен на
трёхуровневой архитектуре (API → Business Logic → Data Access) и использует
полиглотную персистентность: реляционные данные в PostgreSQL, чат — в MongoDB,
сессии и кэш — в Redis, уведомления — через RabbitMQ, файлы — в MinIO.

## Какую проблему решает

Классические форумы статичны — нет живого общения. Мессенджеры не дают
структурированного обсуждения тем. IDK объединяет оба формата: можно вести
тематические обсуждения в постах с вложенными комментариями и одновременно
общаться в личных и групповых чатах в реальном времени — всё в рамках одного
бэкенда с единой аутентификацией.

## Сильная сторона

- **Полиглотная персистентность** — каждая задача решается подходящим хранилищем:
  PostgreSQL для структурированных форумных данных, MongoDB для гибкой структуры
  чата, Redis для быстрых сессий и кэша.
- **Реал-тайм через WebSocket + RabbitMQ** — сообщения доставляются мгновенно,
  асинхронные события (непрочитанные, push, архивация) не блокируют API.
- **Контент-фильтр** — автоматическое обнаружение угроз и вымогательства в
  комментариях на основе regex-паттернов.
- **Безопасная аутентификация** — Argon2-хэширование паролей, cookie-сессии в
  Redis с TTL, авто-рехэш при устаревании параметров.
- **Rate limiting** на сообщения и распределённые блокировки через Redis.

## Особенности

- **Древовидные комментарии** — поддержка вложенных ответов через `parent_id`
  с каскадным удалением.
- **Контент-фильтр** — автоматическая блокировка угроз и вымогательства в
  комментариях на основе regex-паттернов (`content_filter.py`).
- **Cursor-пагинация сообщений** — эффективная подгрузка истории чата через
  `before_id` / `after_id` без offset.
- **Redis-кэш с distributed lock** — защита от cache stampede через
  `SET NX EX` + Lua-скрипт для освобождения блокировки.
- **Асинхронные уведомления** — RabbitMQ обрабатывает инкремент непрочитанных,
  push-уведомления и архивацию сообщений вне цикла запроса.
- **WebSocket-менеджер** — мультиплексирование соединений по `user_id`,
  broadcast по диалогам, автоматическая очистка мёртвых соединений.
- **Soft-delete** — сообщения и комментарии помечаются удалёнными, а не
  стираются физически.
- **Маскировка email** — в ответах API email частично скрыт (`a***@domain.com`).
- **Структурированное логирование** — каждый запрос логируется с методом,
  путём, статус-кодом и временем выполнения.

## Запуск

```bash

git clone https://github.com/eperfilev00-hash/IDK
cd IDK

# Копируем .env
cp .env.example .env

# Поднимаем всё через Docker
docker compose up --build

```
## Структура
```
├── app/
│   ├── main.py              # Точка входа, lifespan, middleware
│   ├── config.py            # Настройки (pydantic-settings)

│   ├── database_mongo.py    # MongoDB (Motor + Beanie init)
│   ├── logging_config.py    # Настройка логирования
│   ├── models/              # SQLAlchemy-модели (User, Post, Comment)
│   ├── schemas/             # Pydantic-схемы запросов/ответов
│   ├── routes/              # Роутеры (auth, posts, comments, chat)
│   ├── services/            # Бизнес-логика
│   ├── repository/          # Слой доступа к данным
│   └── alembic/             # Миграции БД
├── docker-compose.yml       # PostgreSQL, Redis, MongoDB, MinIO, RabbitMQ, App
├── Dockerfile
├── entrypoint.sh            # alembic upgrade + uvicorn start
└── reqs.txt                 # Зависимости
```
