* Стек проекта: python3.12, fastapi + psql на pydantic
* Перед ЛЮБЫМИ изменениями ты советуешься со мной вне зависимости от твоего режима
* Все комментарии которые ты добавляешь дожны быть на английском языке
* Сначала делай модульным. Никаких файлов кода длиннее 300 строк! Документация, планы и т.д. могут быть любой длины, но файлы кода должны быть модульными.
* Думай наперёд! Не пиши код, который, как ты знаешь, придётся менять позже, не планируя это изменение сейчас. Поэтому держи точки входа стабильными и с самого начала изолируй логику в небольшие модули!
* Не ограничивай себя из-за лимита строк кода! Если задача требует больше кода, разбей её на несколько файлов/модулей/функций.
* Не добавляй стандартные запасные варианты во время фазы разработки. Если что-то не работает, пусть не работает, чтобы мы могли это исправить!
* Не изобретай велосипед! Используй open source, самохостинговые библиотеки, когда это необходимо. Спроси пользователя и помоги ему оценить свой выбор.
* Проектируй UI для конечного пользователя, а не для схемы!
* Следуй принципу Keep It Stupid Simple («Придерживайся простоты») и Don't Repeat Yourself («Не повторяйся»)
* Проект использует Three-Tier Architecture API -> Business Logic -> Data Access
